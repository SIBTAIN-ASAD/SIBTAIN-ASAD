# Logo sources

Technology brand marks are from [Simple Icons](https://github.com/simple-icons/simple-icons), npm package version 16.34.0, distributed under [CC0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). Brand names and marks remain the property of their respective owners. Badge colors follow the profile section palette. Generic outline glyphs represent concepts or tools without a supplied brand asset; they are not official logos.

User and organization avatars are embedded from the public GitHub avatar URLs returned by the GitHub API for SIBTAIN-ASAD, apache, typeddjango and amd.
